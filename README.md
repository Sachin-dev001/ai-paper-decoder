# 🧠 AI Paper Decoder

AI Paper Decoder is an AI-powered research paper explainer built using LangChain, Gemini API, and Streamlit.

This application helps users understand famous AI research papers in a beginner-friendly and interactive way.

---

# 🚀 Features

- 📄 Explain famous AI research papers
- 🧠 Multiple explanation styles
- 📚 Adjustable explanation length
- 📊 Difficulty indicator
- 🎨 Dark modern UI
- 📥 Download generated explanations
- ⚡ Powered by Gemini 2.5 Flash
- 🌐 Streamlit web interface

---

# 🛠 Tech Stack

- Python
- Streamlit
- LangChain
- Gemini API
- Prompt Engineering

---

# 📄 Supported Research Papers

- Attention Is All You Need
- BERT
- GPT-3
- GPT-4 Technical Report
- LLaMA
- RAG
- Chain of Thought Prompting
- LoRA
- Diffusion Models
- DDPM
