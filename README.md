# 🧠 AI Paper Decoder

AI Paper Decoder is an AI-powered research paper explainer built using LangChain, Gemini API, and Streamlit.

This application helps users understand complex AI research papers in a beginner-friendly and interactive way using Large Language Models (LLMs).

---

# 🚀 Features

- 📄 Explain famous AI research papers
- 🧠 Multiple explanation styles
- 📚 Adjustable explanation length
- 📊 Difficulty indicator for papers
- 🎨 Modern Dark AI-themed UI
- 📥 Download generated explanations
- ⚡ Powered by Gemini 2.5 Flash
- 🌐 Interactive Streamlit web interface
- 👨‍💻 Developer branding section
- 🔥 Startup-style user interface

# ▶️ Run Locally

## 1️⃣ Clone Repository

```bash
git clone https://github.com/Sachin-dev001/ai-paper-decoder.git
---

## 2️⃣ Move Into Project Folder

```bash
cd ai-paper-decoder
```

---

## 3️⃣ Install Requirements

```bash
pip install -r requirements.txt
```

---

## 4️⃣ Add Gemini API Key

Create a `.env` file in the project folder:

```env
GOOGLE_API_KEY=your_api_key_here
```

---

## 5️⃣ Run Streamlit App

```bash
streamlit run app.py
```

# 🧠 How It Works

1. User selects a research paper
2. User chooses explanation style and length
3. LangChain loads the prompt template
4. Gemini 2.5 Flash generates the explanation
5. Streamlit displays the formatted AI response
